# Cohabit (Arsist プロジェクト)

[`Cohabit_v4.1.md`](../Cohabit_v4.1.md) の **Quest 3 側のアプリ**。PC 側は [`CohabitPC`](../CohabitPC/README.md) (Cohabit PC)。
Arsist に足した汎用の機能 (キャラクターの動き・声・カメラの静止画・端末への保存・部屋での隠れ・`ui.on` など) だけで組んであり、
エンジンに Cohabit 専用のものは入れていない。アプリ固有のことはすべて、このプロジェクトのスクリプト 10 本に書いてある。

エディタでは「プロジェクトを開く」でこのフォルダを選ぶ。

**勉強の中身は PC の先生がする。** 問題を出す・ノートを読む・ヒント・説明・答え合わせは、タブレット版と同じ「PC の先生」
(Cohabit PC の `/tablet/api/*`、教科を決めない LLM) に頼む。Quest は式を計算しない。今の問題と学習記録は PC にあり、
タブレットで始めた問題は Quest をかぶってもそのまま続く。Quest が自分で決めるのは「いつ話しかけるか」(手の止まり方・Lev の順位・
断られた回数) と、妹としての振る舞いだけ。

方針は **性能より安定**: どの通信にも時間切れがあり、用事ごとに同時に 1 本。PC の LLM には同時に 1 つしか頼まない。
PC が無くても勉強 (タイマー・妹がそばにいる) は続き、妹は「PC とつながってない」を 1 分に 1 回までしか言わない。

## 動かす前にすること

| すること | どこで |
|---|---|
| PC で Cohabit PC を起動し、その画面の「設定」で API キー・VOICEVOX・Lev を決める | `CohabitPC` (`start.bat` / `start.sh`) |
| Quest と PC を同じ LAN (Wi-Fi) につなぐ。**アドレスを入れる必要はない** (下の「自動でつながる」) | Windows のファイアウォールが聞いてきたら「プライベート ネットワーク」を許可 |
| (任意) 動きの FBX を入れる — 今は動きのファイルを入れていない。動きが無いとき、エンジンは腕を下ろしてゆっくり揺れる立ち姿にする (T ポーズにはならない)。妹は歩かずに、席・机の横・呼ばれた所へその場に現れる | 入れるならシーン → Sister → インスペクタ「キャラクター」→ FBX を読み込み、スクリプトから `vrm.playAnimation` で使う |
| (済) VRM 1.0 の読み込み | Sister は VRM 1.0。公式の拡張機能「VRM 1.0」(`Extensions/vrm10`) を有効にしてある |
| Quest でスペースの設定 (部屋のスキャン) を済ませておく | ヘッドセット。机が見つからないと、問題の板は机の上ではなく目の前に出る |

## 自動ですること

| いつ | 何を |
|---|---|
| 起動したとき | **PC を探す**: 前につながったアドレス → スクリプト「設定」の `CONFIG.server` (`192.168.0.12:8000`) → 同じネットワーク (/24) を最後のアドレスに近い順に 16 台ずつ (`GET /health` が `"app": "cohabit-pc"` を返す所)。見つけたら覚える (次からはすぐつながる)。HUD の右上は「● PC を探しています…」→「● PC 接続中」 |
| PC が落ちた / 見つからない | 10 秒ごとの確認で 2 回続けて返事が無ければ「探しています」に戻り、最後のアドレスを 5 秒ごとに試す。同じネットワークを探し直すのは 1 分に 1 回まで。一通り探して見つからなければ「● PC が見つかりません」と、起動を促す 1 行を一度だけ出す |
| 起動したとき | マイクを開く (初回は端末が許可を聞く。設定で切れる。開けていなければ 5 秒ごとに開き直す。外してかぶったときも開き直す)。妹が席 (なければ近くの床) に出てきて、目が合ったら 1 回だけあいさつ |
| 勉強を始めたとき | タイマーが始まり、妹が隣 (右斜め前 0.85 m) に現れる。写真の同意がまだなら 1 回だけ聞く。**問題は勝手に出さない** (下の「何やる？」) |
| 勉強中 | 5 秒ごとに PC の今の問題を見る (タブレット・PC の画面で出した問題もこちらに出る)。手 (右手の人差し指) が書く動きのあとで 4 秒止まると、見ている机の 50cm 四方を撮って PC の先生に見せる (20 秒に 1 回まで・同意があるときだけ)。先生が間違いを見つけたときだけ妹が言う。迷っていそうなら、Lev の順位で「ヒントいる？」/ ヒント / 励ます / 黙る を選ぶ (断られるほど待つ時間が延びる) |
| 解けたとき | 板に「正解！」。9 秒後に**同じ単元**の次の問題 (PC が前の結果から難しさを決める。「今日は終わり」と言えば止まる) |
| ヘッドセットを外した / かぶった | 外すと勉強を休憩にし、マイクを止め、PC に「外した」を知らせる (タブレットの妹が出てくる)。かぶると、外したところから勉強を続ける。30 分以上外していたら、もう一度だけあいさつ |
| 勉強していないとき | 3 分に 1 回まで、机の上の見慣れない物を見て、区切りで「あれなに〜？」。設定「部屋を歩く」を入れたときだけ、1.5〜3 分おきに、妹を見ていない間に近くの家具の手前へ移って触って遊ぶ (床があり・家具の中でなく・ユーザーから 0.6 m 以上の所だけ。勉強を始めると止まる)。**最初は切** |

## 今どうなっているか (字幕の上の 1 行)

HUD の字幕のすぐ上に、いつも小さく 1 行出る。PC の画面の「妹の今」にも同じもの (`status.stage`・`stageKind`・`micStatus`) が出る。

| 出るもの | 意味 |
|---|---|
| `マイク ●●●・・` | マイクが聞いている。● が今の音量 (5 段)。話すと ● が増えるはず。増えなければ声が届いていない |
| `マイク オフ` / `許可待ち` / `許可されていない` / `マイクが無い` / `開けない` | マイクが動いていない。「許可されていない」は Quest の設定 → アプリ → 権限 → マイク で許可する (設定パネルの「マイク」にも出る) |
| `話しています…` | 声が「話し始め」の音量を超えている (quest-input の `voiceThreshold` 0.35 ≈ -39 dBFS) |
| `文字にしています… n秒` | 話し終わった声を PC で文字にしている |
| `あなた: 「…」` | 聞き取れた言葉 (6 秒)。`聞き取れなかった` は文字が空か失敗。`(妹の声を拾ったので無視)` は妹のスピーカーの声を拾っただけ |
| `考え中… n秒 (問題を作っています / ヒント・説明 / 採点 / ノートを見ています / おしゃべり)` | PC の LLM の返事を待っている。`順番待ち n` は、その後ろに頼んだ用事が待っている |
| `妹が話しています` | 妹の声が鳴っている (`(字幕)` は声が出せず字幕だけ) |
| `(裏でノートを見ています n秒)` | 手が止まったときのノート確認。頼んだ用事はこれを待たずに送る |
| `× PC から返事が無い` / `× LLM が答えない` / `× LLM の回数制限。少し待って` / `× PC につながっていない` | 失敗 (8 秒で消える) |

勉強中に 60 秒、声が 1 度も「話し始め」の音量に届かなければ、「声が届いていないかも (マイクの許可・音量)」を 1 回だけ出す。

ノートの確認 (手が止まったとき) は PC の LLM を占めないように、前の確認から **max(45 秒, 前の確認にかかった時間の 3 倍)** あけ、
そのあいだに書いたときだけ、ほかの用事 (声を文字にする・ヒント・採点・問題・おしゃべり) が走っていない・待っていないときだけ送る。

## 何やる？ (勉強を始めたときの問題の決め方)

A を押す / 「勉強始める」と言うと、タイマーと妹はすぐ始まる。問題だけは、ユーザーが決めるまで出さない。

1. PC に今の問題がある (タブレットで始めた等) → 妹「さっきの『…』の続き、やる？」。板にもその問題と「「うん」で続き / 「別の」で選び直す」。
   「うん / やる / 続き」で続き、「別の / いや」か 20 秒返事が無ければ 2 へ
2. 妹「今日は何やる？ 教科とか単元を言って」。板に「今日は何やる？」と例 (英語の現在完了 / 数学の二次関数 / 苦手なの / おまかせ)。
   次に言ったことが単元になる (`POST /tablet/api/problem { from: "topic", topic }`。「〜をやりたい」「〜の問題出して」の言い回しは落とす)
3. 「苦手なの」「おまかせ」→ 苦手から (`from: "weak"`)。まだ記録が無ければ (409 `no_records`) 妹「まだ記録が無いから、何をやるか教えて」で 2 のまま聞き続ける
4. マイクが止まっている / PC につながっていないときは、板にそう出して待つ (勝手に選ばない)。PC につながると、改めて聞く

あとから変えるとき: 「〇〇の問題出して」「別の問題」(→ 何やるか聞き直す)「次の問題」(同じ単元)「苦手な問題出して」「もっと簡単なの出して」。


## 使い方 (ヘッドセットの中)

| 操作 | |
|---|---|
| 右手 A | 勉強の開始 / 終了 (休憩中なら再開) |
| 右手 B | コントローラーで床かソファを指して、妹の席を決める (空間アンカーで覚え、次に起動しても同じ場所に座る) |
| 左手メニュー / Y (または「設定」と言う) | 設定パネル |
| 声 (勉強) | 「勉強始める」「休憩」「続きやる」「今日は終わり」 |
| 声 (問題) | 「何やる？」には単元を言う (例: 英語の現在完了・数学の二次関数)、「苦手なの」「おまかせ」。あとから「〇〇の問題出して」「別の問題」「次の問題」「もっと簡単なの出して」「難しいのにして」 |
| 声 (今の問題) | 「答えは …」(言ったまま PC の先生が採点)「ヒント」「わからない / どうやるの？」(説明)「答え教えて」「見て / 合ってる？ / できた」(ノートを見せる)。「ヒントいる？」には「お願い / いらない」 |
| 声 (そのほか) | 「静かにして」「話していいよ」「〇〇どこ？」「〇〇のこと忘れて」、ほかは妹とのおしゃべり (勉強中の質問は PC の先生へ) |

HUD の下の行に最初の 40 秒だけ「A: 勉強  B: 妹の席  メニュー: 設定  声:「ヒント」「答えは…」」と出る。

## PC が要るもの / 要らないもの

| | PC がつながっているとき | PC が無いとき |
|---|---|---|
| 問題・ヒント・説明・答え合わせ・ノートを見る | PC の先生 (LLM) | できない (妹が 1 分に 1 回まで「PC とつながってない」と言う) |
| 声を聞く (音声認識)・読み上げ・おしゃべり | PC (`/v1/audio/*`・`/v1/chat/completions`)。声は PC の先生の `say.audio` か `/v1/audio/speech` | 字幕だけ。声は聞き取れない |
| 話しかけるかの判断 (Lev) | PC (`/decision/evaluate`)。落ちていれば端末の決まり | 自分からは話しかけない |
| 勉強のタイマー・妹がそばにいる・席・遊ぶ・記憶・設定 | 端末 | 端末 (そのまま動く) |
| 何をやるか決める | 声で単元を言う → PC の先生が問題を作る | 板に「PC につながったら、声で教えてね」と出して待つ |

## 画面

- **視界 (HUD)**: 上に勉強の状態と経過時間・教科、右上に PC とのつながり、その下に推論の実行先 (仕様 11.3)・「見ている机の 50cm 四方を
  PC へ送っています」(送っている間だけ)・お知らせ (PC につながった / 見つからない)、下に今の段階の 1 行 (上の表)・妹の字幕 (話し終わると消える)・操作の案内 (最初の 40 秒)
- **大きさと距離**: HUD は左右 ±17°・上 12°・下 14° の中、文字 1.15° 以上 (字幕 1.6°)。板 (設定・同意・アドレス) は目の前 0.9 m、
  机の問題は幅 40 cm (目の前に出すときは 0.75 m)。妹は勉強中は右斜め前 0.85 m (約 70°)、呼ぶと 1.25 m
- **問題の板** (`Quiz`): 紙のような板。上に教科と「できればよいこと」、真ん中に問題文 (PC の先生が Unicode で書いたもの。書いていくように出る。
  150 字まで)、下に答え方。解けると「正解！」。問題が決まるまでは「今日は何やる？」「続き、やる？」を出す。勉強を終えると消える (問題は PC に残る)
- **設定パネル** (`Settings`): PC のアドレスとつながり・推論の実行先、写真を送る / マイク / 長い記憶 / 話しかける / 部屋を歩く の入り切り、
  覚えていること (新しい順)、消す (今日の記憶・関係・物の記録・席・全部。**2 回押すと消える**)、「アドレス変更」「PC を探し直す」。
  学習記録は PC にあるので、PC の画面の「データ」で消す
- **アドレスの入力** (`Address`): 自動で見つからないときだけ使う。数字のキーボード。`192.168.0.23` だけ打てばよい (`http://` と `:8000` は足す)
- **写真の同意** (`Consent`): 初めて勉強を始めたときに、何を・どこへ送るか・保存しないことを見せて聞く。「送っていい / 送らない」
  (声でも「いいよ / だめ」)。断ったら撮らない (ヒントは声だけで頼める)。返事が無ければ 1 分で板を下げ、10 分は聞き直さない

## 中身

- **シーン**: `Sister` (VRM。動きのファイルは無く、力を抜いた立ち姿・まばたき・呼吸・近くで見られたら見返す)、`Quiz` / `Settings` / `Address` / `Consent` (板。
  スクリプトが出し入れする。エディタでは横に並べてある)、`Seat` (妹の席の印。見えないほど小さく、空間アンカーに留める)
- **UI**: `HUD` (視界)、`Quiz`、`Settings`、`Address`、`Consent`。エディタの UI タブで見た目を変えられる (スクリプトが入れる文字は、エディタでは空)
- **拡張機能**: `quest-room` (部屋・机・本物の家具で隠す・空間アンカー)、`quest-input` (手・コントローラー・マイク・着脱)、`quest-hands`、`vrm10`。
  スクリプトは、これらが無い端末でも止まらない (`room` / `controller` / `hands` / `mic` / `headset` があるときだけ使う)
- **端末に保存する値**: `memory.` (出来事・物・関心) `relation.` `settings.` (`learning.` は前の版の学習記録。今は使わず、「全部消す」で消える)
- **スクリプト** (上から順に起動時に読まれ、「毎秒」だけが 1 秒ごとに動く)

| スクリプト | 中身 |
|---|---|
| 設定 | `CONFIG` (最初に試す PC `http://192.168.0.12:8000`・合言葉)、例外を外に出さない小物 (`attempt` / `safe` / `later`)、通信 (`Net`: 用事ごとに 1 本・時間切れ・見張り)、LLM の順番 (`Llm`: 頼まれた用事は同時に 1 本・2 つまで待たせる、裏の用事はほかに何も無いときだけ 1 本)、今の段階の 1 行 (`Stage`)、PC を探す・つながりを見る・着脱を知らせる (`PC`)、PC の画面への記録 (`/observe`、200 件まで)・操作ボタン (`/control/next`)、HUD |
| 記憶 | 出来事に時刻・出どころ・確かさ (200 件まで)、物は「最後に見た場所」(60 件まで)、関係、消す (仕様 7.3 / 5.5 / 11.4 / 25) |
| 声と会話 | 音声認識 (同時に 1 本、待つのは最後の 1 つ) → 振り分け → 読み上げを妹の位置から (新しい言葉が来たら前の声を止める・PC の `say` の表情と声)、字幕、おしゃべりは LLM (記憶に無いことは言わせない)、「PC とつながってない」は 1 分に 1 回 |
| PC の先生 | `/tablet/api/problem` `ask` `answer` `check` `session` の窓口。机の写真 (`Desk`)。返事は、送ったときと問題が変わっていれば捨てる。「何やる？」(続けるか聞く・単元を聞く・苦手から)。409 なら PC と合わせ直す (勉強中なら何をやるか聞き直す。次の問題をもらう) |
| 一緒に勉強 | 開始 / 休憩 / 終了、声の振り分け、手の止まり (仕様 5.4: 見えなければ「不明」で口を出さない)、手が止まったらノートを先生に見せる、話しかけるかを Lev に (仕様 6.4)、断られたら待つ時間を延ばす (7.4) |
| 問題の板 | 問題を机の上 (ノートの右) か目の前に出す。同じ問題の間は置き直さない (仕様 6.7) |
| 部屋にいる | 席 (空間アンカー)、あいさつ (1 回)、現れる前に立てる所か確かめる (歩く動きが無いので歩かない)、家具を触って遊ぶ (最初は切・25 秒で必ず終わる・勉強で止まる)、頭を撫でる、着脱 |
| 気になる物 | 見慣れない物を関心として保留 → 区切りで聞く / 眺める / 待つ / やめる を Lev で比べる → 答えを覚える (仕様 18 / 19 / 27.1)。勉強中は見ない |
| 設定パネルと同意 | 同意、設定パネル、アドレス、PC の画面の操作ボタンの割り当て |
| 毎秒 | 上の各部の 1 秒ごとの処理。どの段も例外を外に出さない (失敗のログは同じ場所 1 分に 1 回) |

## PC の画面の操作ボタン

勉強を始める / 休憩 / 終わる / 「ヒントいる？」/ ヒント / 問題を出す (勉強していなければ始める。問題がまだ無ければ「何やる？」を聞く) /
そばに来る / 気になる物を考える / 静かに / しゃべらせる が Quest で動く。

## 確かめたこと / 確かめていないこと

- 2026-10-27: 10 本すべて `arsist validate` (警告 0) と `ir_check_script` を通した。Node の上で、端末の API と Cohabit PC の約束どおりの
  偽物 (時刻も偽物) につないで流した — A では問題を取りに行かない・「何やる？」→「おまかせ」で 409 `no_records` →「まだ記録が無いから…」で
  聞き続ける・「英語の現在完了をやりたい」→ `topic` で出題・正解 → 次は `next` だけ・PC に問題があれば「続き、やる？」→ 20 秒黙ると聞き直す /
  「うん」で続き・マイクが止まっていると板に出して待つ・PC が落ちて戻っても勝手に出題しない・「〜の問題出して」・遊ぶ (最初は切、入れると
  見られていない間に移る)。LLM は同時に 1 本、スクリプトの例外 0
- **実機 (Quest 3) では、この版はまだ動かしていない**。最初は `npm run logs` で `[ArsistJS]` と `[Arsist]` を見る。
  特に確かめたいのは: PC が自動で見つかるか (ファイアウォール)、「何やる？」の聞き取り、手が止まったときに写真が送られるか、`say.audio` の声、
  家具の判定 (`room.raycast` の `label` が `floor` で返るか — 返らないと妹はその場から動かない)
